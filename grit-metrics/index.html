How each test is auto-measured

Vertical: Head rise (px) ÷ (Person height px ÷ Athlete height) = inches.
Broad: Feet start → feet land distance (px) ÷ same scale = inches / feet.
Swing: Fastest bat-tip motion across frames. Bat tip speed ≈ distance moved between frames × fps, scaled by athlete height. Shows mph. Best in bright light, side view, full swing in frame.
20-Yd: Motion start (first big move) → motion crosses finish side of frame. Time × 20 yards = time. For best accuracy film from side, start line left, finish line right, whole 20 yd in frame. If camera is too close, time will be LOW confidence — re-film wider.
