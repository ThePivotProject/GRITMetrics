FIXED: Center-only tracking

Last version tracked the whole frame, so it locked onto the plant at the top (Standing top: 8px). This version only looks at the center 25%-75% width, 20%-98% height — where the person is. Plant, fireplace, furniture at edges are ignored.

Why last version failed

Vertical: Old code needed fast motion per frame. Slow-mo = slow motion per frame, so it never triggered. New code tracks head height over the whole video, not motion speed.
Swing: Old code had a 20mph floor and used body centroid (which barely moves). New code tracks the fastest-moving pixels (the bat) and has NO floor — if it sees 45mph, it shows 45mph, if it sees 62mph, it shows 62mph.
